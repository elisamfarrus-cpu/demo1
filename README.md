# Demo1

> Proyecto demo con HTML, CSS y JavaScript.

Proyecto de demostracion que muestra una pagina web basica con estilos y estructura de archivos organizada.

## Estructura del proyecto

`
demo1/
  index.html    # Pagina principal
  styles.css    # Estilos
  demo1.txt     # Archivo de notas
  .vscode/      # Configuracion de VS Code
`

## Uso

Abre index.html directamente en tu navegador o utiliza un servidor local:

`ash
# Con Python
python -m http.server 8000

# Con Node.js (npx)
npx serve .
`
